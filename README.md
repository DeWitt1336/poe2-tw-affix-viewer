# POE2 繁中詞綴查看器

一個精簡、離線優先的《Path of Exile 2》繁體中文詞綴查看工具。

貼上官方 Trade 或遊戲的 Copy Item Text，即可識別物品種類、底子與物品等級，並查看該 ilvl 可出的各來源前綴、後綴、Tier、需求 ilvl、weight 與池內機率。

## 功能

- 識別英文與常見繁中格式的裝備文字。
- 物品種類、底子與詞綴優先顯示繁中名稱。
- 有進階詞綴標頭時直接依 Prefix／Suffix、詞綴名與 Tier 識別。
- 正確合併同一個 Modifier 區塊中的多行復合詞綴，不會誤刪對應的單項詞綴。
- 高級複製時自動排除物品已有的詞綴系列，並重新計算剩餘詞綴機率。
- 依物品等級過濾尚不可出現的 Tier。
- 分開顯示基礎通貨、褻瀆、精髓、裂痕、合金、腐化等來源。
- 支援區塊收合與繁中／英文搜尋。
- 純 HTML、CSS、JavaScript，不上傳裝備文字，不需要安裝或登入。

## 使用方式

1. 直接雙擊 `index.html`，用 Chrome、Edge 或 Firefox 開啟。
2. 在遊戲內將滑鼠移到裝備上按 `Ctrl+Alt+C`，可取得帶詞綴名稱與 Tier 的進階文字，識別最準；也可使用官方 Trade 的 Copy Item Text。
3. 在文字框按 `Ctrl+V`；工具會自動解析。也可以按「查看詞綴」。

瀏覽器可能不允許本機頁面直接讀取剪貼簿；這時手動 `Ctrl+V` 即可，不影響功能。

## 更新詞綴資料

- GitHub：進入儲存庫的 `Actions → 更新数据库并部署网站 → Run workflow`，GitHub 會自動重建、提交資料並更新線上版。
- macOS：雙擊 `update-data.command`。
- Windows／其他系統：在此資料夾執行 `python3 tools/update_data.py`。

腳本會下載 PoE2DB 最新英文與繁中頁面，再自動重建 `affixes-data.js`。只需要 Python 3，不需安裝額外套件；若下載或頁面解析失敗，現有資料不會被覆蓋。

## 目前範圍

- 支援一般護甲、武器、盾、法器、箭袋、戒指、項鍊與腰帶。
- 支援英文，以及常見繁中欄位名稱的裝備文字。
- 物品種類與底子會優先顯示 PoE2DB 繁中名稱。
- 最上方單獨顯示複製文字中已有的詞綴；可匹配的英文词句會轉為繁中。
- 普通 `Ctrl+C` 或市集 Copy Item Text 可能只有最終合計值，無法可靠判斷復合詞綴，因此不判定 Tier，也不從下方詞綴池剔除。
- 遊戲內使用 `Ctrl+Alt+C` 高級複製時，文字會包含 Modifier 標頭；此時才識別 Tier、剔除已有詞綴系列並同步重算 weight 機率。
- 依序分為基礎通貨、褻瀆、精髓、深淵、完美精髓／合金、裂痕、特殊符文系列、奉獻寶珠升級與瓦爾腐化附魔。
- 大區塊可收合；基礎通貨預設展開，其他特殊來源預設收起。
- 只有一個等級的詞綴會直接顯示明細；多 Tier 詞綴才需要展開。
- 可用繁中、英文詞句或來源名稱搜尋；搜尋只篩選畫面，不改變機率。
- 每個來源仍分開顯示前綴與後綴；不屬於前後綴的結果獨立顯示。
- 機率按當前物品等級可用的 Tier 動態計算：單一 Tier weight ÷ 同來源、同前／後綴池的有效 weight 總和。
- 普通、完美與深淵精髓為指定必出，不計算隨機機率；深淵的「褻瀆詞綴」則按其來源池內 weight 計算。
- 不含查價、交易、BD、開荒、地圖、Regex 或其他工具功能。
- 詞綴池由生成時下載的 PoE2DB 中英對照頁面建立；若遊戲改版，需重新生成資料。

## 線上部署

本工具可直接部署到 GitHub Pages。將所有檔案放在儲存庫根目錄後，在 GitHub 的 `Settings → Pages` 選擇從 `main` 分支根目錄部署即可。
